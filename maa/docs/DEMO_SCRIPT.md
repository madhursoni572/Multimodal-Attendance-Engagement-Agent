# Demo video script (about 4-5 minutes)

**Before recording:** server running, the staged test clip ready, browser zoom 110%, notifications off,
GitHub repo and demo link open in tabs. Record with OBS Studio (Windows/Mac/Linux), Win+G (Windows) or Cmd+Shift+5 (Mac).

| Time | Show | Say |
|---|---|---|
| 0:00 | Landing page hero | "Manual attendance is slow, and biometric systems tell you nothing about engagement. This is Classroom Pulse, a privacy-preserving agent that does both." |
| 0:30 | Features section | "Three scenarios: automated attendance, engagement analysis and teaching suggestions." |
| 0:50 | architecture.svg | "Video goes through face detection and tracking, audio through noise and speech analysis. The multimodal agent fuses both and scores engagement. Everything runs on our own server." |
| 1:30 | Upload the clip, progress bar | "I upload a recorded session. The video is deleted as soon as analysis finishes." |
| 2:00 | Stats + attendance table | "Presence is based on sustained time, not one frame. P3 walked past briefly, so is not counted. P2 arrived late and the intervals show when each person was in view." |
| 2:40 | Timeline chart + colour strip | "Every 30 seconds gets a score from attention, movement, stillness and speech. Here is the attention drop." |
| 3:20 | Teaching suggestions | "The agent suggests a poll or break at the drop. It assists the teacher and never decides." |
| 3:45 | Mic meter tab | "Live microphone analysis shows noise level and speech activity." |
| 4:10 | Download CSV; README test table | "Logs export to CSV. In testing, attendance error was X of Y people." |
| 4:40 | Repo + demo URL on screen | "Code is on GitHub and a live demo is linked below. Thank you." |
